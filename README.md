# Wilmot's Warehouse 简体中文 Mod

适用于 Steam Windows 版 1.0.5。

1. 退出游戏，下载 [安装包](https://github.com/Zhou-ten/wilmot-warehouse-zh/raw/refs/heads/main/Wilmot-Warehouse-ZH-v0.4.0.zip)。已有 `wilmzh.dll` 的玩家下载 [旧版升级包](https://github.com/Zhou-ten/wilmot-warehouse-zh/raw/refs/heads/main/Wilmot-Warehouse-ZH-v0.4.0-legacy-update.zip)。
2. 在 Steam 游戏属性中选择「已安装文件 → 浏览」。解压 ZIP，把里面的 `WilmotPC` 文件夹复制到打开的游戏目录，选择合并并覆盖。
3. 从 Steam 启动游戏，按 **F8** 切换中文和英文。
